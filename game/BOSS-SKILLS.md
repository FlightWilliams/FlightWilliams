# 96位关卡Boss主动技能 · 六重轮回 0.18

六个轮回依次为黑暗之魂Ⅰ、黑暗之魂Ⅱ、黑暗之魂Ⅲ、血源诅咒、只狼、艾尔登法环，每轮16关。下表按实际关卡顺序列出96位守关者；配置文件另保留旧版12位恶魂／幽影Boss的技能，兼容已有内容。

这些是关卡Boss的主动能力，不要求同名卡牌在场，不改变同名卡牌的印刷技能。从第2回合开始，每次成功发动固定消耗1张未冻结的手牌余灰，原表内代价另付；随后跳过下一完整回合，再下一回合可使用。没有合法目标或支付不起代价时不扣余灰、不进入冷却。技能名显示在Boss红名旁，电脑悬停或点击、手机点按即可查看效果、时机、代价与当前状态；阅读不暂停或重绘战斗。

“Boss部署时”指本轮实际敌方部署阶段；“攻击结束后”指双方攻击都已结算。每轮回首关由金龙币决定先手，此后逐关交替；同一场内逐回合交换先部署与先攻的一方。双方空牌桌开局，各有5张起手牌，包含1张余灰。

临时加攻、减攻、属性、附加技能与护盾等在本轮结束时清除，永久成长不会一起撤销。Boss召唤物须存活一轮才可献祭；明确标为不可献祭的幻影和风暴鳐不能献祭。普通卡原有攻防与费用未在本版调整。

玩家可借用下列同名Boss的主动技能：将自己的普通或金辉Boss卡部署上场，点击我方生命旁的“装备战技”。第2回合起每回合最多装备一次；成功发动支付手牌余灰并冷却下一完整回合，装备可沿用，来源离场或化灰后失效。下表中的“玩家”在玩家借用时指电脑对手，“Boss”指技能使用者；自己的卡、手牌、生命与牌库支付代价。部署类由玩家点击发动，攻击后类先准备、攻击结束后结算。敌方Boss仍按原条件自动使用。新规则详见[0.18说明](UPDATE-0.18.md)。

## 弃牌与回收

双方弃牌堆可在战斗记录中查看。主动弃手牌不触发亡语、死亡抽牌或复燃；正常死亡／献祭的非衍生卡进入弃牌堆。复燃回手的牌不同时进入弃牌堆，余灰、骨与衍生物不入堆。回收移动原实例，不能复制；抽牌消耗有限牌堆，不足时只抽剩余的牌。

## 暂时余灰化与冻结

暂时余灰化把一张合法玩家场上卡变为0攻1血、无原技能的余灰，覆盖玩家下一次完整行动，之后恢复原卡当前攻血、成长与状态，不回满血、不重触入场。刚恢复的卡免疫一轮再次变形。余灰被杀或献祭后原卡本场不再恢复，也不触发原卡亡语；永久收藏不受影响，衍生物与已有余灰不作为变形目标。

Boss白王冰封不附带减费；帕奇的手牌冻结与减费独立处理。具体持续时间、条件及额外限制以各技能说明为准。
