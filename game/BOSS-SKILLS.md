# 48位Boss主动技能 · 0.13

这些是关卡Boss的主动能力，不要求同名卡牌在场，不改变金辉卡原有技能。从第2回合开始，每整轮至多发动一次。没有合法目标或支付不起代价时不消耗次数。技能名在Boss红名旁，电脑悬停或点击、手机点按即可查看效果、时机、代价与使用状态；阅读不暂停或重绘战斗。

临时加攻、减攻、属性、附加技能、护盾等在本轮结束时清除，永久成长不会被一起撤销。Boss召唤物须存活一轮才可献祭；明确标为不可献祭的幻影和风暴鳐不能献祭。普通卡原有印刷数值已完整恢复为0.11，0.12的普通卡平衡调整已经撤销。

## 弃牌与回收

双方弃牌堆可在战斗记录中查看。主动弃手牌不触发亡语、死亡抽牌或复燃；正常死亡/献祭的非衍生卡进入弃牌堆。复燃回手的牌不同时进入弃牌堆；余灰、骨、衍生物不入堆。回收移动原实例，不能复制。抽牌只消耗有限牌堆，不足时只抽剩余的牌。

## 暂时变成余灰

艾尔登之兽、蕾娜拉、马努斯最多同时把一张玩家非衍生的场上卡暂时变为0攻1血、无原技能的余灰。该形态覆盖玩家下一次完整部署和攻击机会，之后在Boss部署开始恢复原卡当前攻血、成长和状态，不回满血，不重触入场。刚恢复的卡免疫一轮再次变形。

玩家可以献祭这张余灰，但灰被杀或献祭后原卡本场不再恢复、不触发原卡亡语，永久收藏不受影响。衍生物与已有余灰不作为变形目标。
