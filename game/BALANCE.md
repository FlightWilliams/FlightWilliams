# 普通卡强度调整 · 0.12

审计880张普通角色卡，48张金辉全部排除并逐字段核对不变。普通牌139张提高生命，222张降低身材，519张保持不变。费用、名称、作品归属、属性与技能不变，调整集中在攻防。
