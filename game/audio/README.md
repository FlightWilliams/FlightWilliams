# 战斗音频与许可

游戏HTML已经内嵌这些声音，运行时不从本目录下载。此处提供独立改编文件与来源。

`burn.wav`（Ezwa，Dinamic改编，Flare来源）及其内嵌PCM按CC-BY-SA 3.0发布，完整许可和改编说明见CREDITS.txt及LICENSE-CC-BY-SA-3.0.txt。

blade、beast、beastAlt、beastBird、beastBull、bow、impact使用CC0来源；magic、spirit、heal、rare为本作原创合成。逐项来源见sources.json，改编信息与校验见manifest.json。

这些音效许可只适用于对应媒体，不更改游戏其他内容的许可。
