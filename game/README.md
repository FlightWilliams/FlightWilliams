## 六个世界，96位守关者

本版按黑暗之魂Ⅰ、黑暗之魂Ⅱ、黑暗之魂Ⅲ、血源诅咒、只狼、艾尔登法环排列六个轮回，每轮16关。通关当前轮回后开启下一轮，难度与电脑决策逐轮提高。魂Ⅰ包含奥斯卡、帕奇、索拉尔等NPC对战；只狼纳入赤鬼、火牛等精英敌人。

所有96位关卡Boss都有实装主动技能、战败余音与玩家死亡回响。技能显示在Boss红名旁；电脑悬停或点击、手机点按可查看效果、时机、代价和本轮状态。第2回合起每整轮至多发动一次，没有目标或代价不足时不发动。主动技能与同名卡牌的印刷技能分别计算。

电脑在全部关卡评估献祭前后的场面，优先保留优势牌与阻止致命直击的阻挡者；随轮回推进，出牌、落点、走位与资源规划更深入。关间恢复逐步收紧，后期敌军也获得额外战斗强化。

## 空牌桌与金龙币

双方由空牌桌开场，不再预放余灰或怪物。双方各有5张起手：4张卡组牌与1张余灰；首回合无需抽牌。双方自行部署，新出场的卡须存活到下一回合才能献祭。

每轮回首关先选择金币旁的“正面”或“反面”，再点击金币投掷。结果在牌桌中央显示：猜中则玩家先部署并先攻，否则Boss先部署并先攻。金币采用受金龙币启发的原创金色龙纹与王冠双面设计。

之后每位Boss的开场先手交替；同一场战斗内，每回合也交换先部署与先攻的一方。双方完成部署后才结算攻击，每张存活卡每回合最多攻击一次。先手改变实际部署和攻击顺序。

## 每轮通关，金辉三选一

每个轮回第16关通关后，必定提供该作品三位不同Boss的金辉卡，选择一张加入牌组；包含当前最终Boss的金辉。六个轮回均采用此规则。普通关卡奖励仍有5%概率出现当前Boss金辉，三张候选选一张。

基础卡库共988张角色卡：880张普通卡、108张金辉卡。96位新关卡Boss各有金辉版本；旧版恶魂与黄金树幽影的12张金辉继续保留，已有收藏和牌组可继续使用。新增60张金辉，攻防高于对应普通版，费用不高于普通版。原有928张卡的字段保持0.13版本，未重新引入此前撤销的普通卡数值调整。

![轮回最终金辉奖励](preview-final-reward.png)

金辉牌有金色边框、箔面与星点，减少动画模式停用扫光。击杀成长只由自身攻击击杀敌卡触发，每击杀增加1攻，仅本次战斗有效；直击生命、献祭与中毒击杀不触发。亡语在死亡和献祭时触发，敌我一致。小蜘蛛、金色余灰等衍生物不计入108张收集卡；本回合诞生须到下回合才可献祭。

## 收藏、组牌与轮回继承

默认初始卡组16张，起手5张；推荐出战24张，上限36张。未获得的牌以问号背面封存，不显示名称、能力或加入按钮，搜索只匹配已收藏卡。默认起始16张中的12种角色与余灰作为初始收藏。

奖励实际进入出战后才永久解锁；只进入备用时保持封存，须编入出战并保存。出战12–36张，同名最多2张，余灰不受同名数量限制。奖励直接加入卡组，达到36张才提示整理；已满36张或同名已达2张时，新奖励进入备用。可按费用、功能、属性与名称排序，排序仅影响显示。

通关16关后，出战卡组、备用牌和已击败Boss记录沿用至下一轮；最终奖励也会写入保存。首页“我的卡组”可编辑沿用牌组。新建初始自定义卡组保留费用、Boss比例与零费比例限制；跨轮回取得的卡组不会因初始预算被重置。

旧版进度按已通关轮数迁移，不清空已有收藏和沿用牌组：旧版完成0／1／2轮分别继续魂Ⅰ／魂Ⅱ／魂Ⅲ，完成3轮进入血源。旧版12张恶魂／幽影金辉与死亡身份继续保留。

每个16关轮回最多暂存一张死亡身份；首次死亡自动保留，第二次及以后选择保留旧身份或替换新身份。重试只带一张暂存身份。通关本轮16关后，该身份才永久归档并可自由组卡。

## 战斗与操作

双方7点生命、五格战场。卡牌只攻击对位；飞行可越过对位直击，守护能够拦截。从第二回合起，玩家每回合免费获得一张余灰，再选择从有限卡组抽一张牌或再取无限余灰。最多36回合，之后按生命与场面裁决。

帕奇出场可冻结一张自己的手牌两回合，第三回合解冻并减1费，最低0费。介绍：“这个光头总是在你不经意时，将你推下深渊”。Boss的白王冰封独立计算，解除不附带减费。

双方弃牌堆可在战斗记录中查看。主动弃手牌不触发亡语、死亡抽牌或复燃；抽牌仍消耗有限牌堆。回收移动原实例，不复制。暂时余灰化覆盖玩家下一次完整行动，恢复原卡当前攻血与成长，不回满血、不重触入场；灰被杀或献祭后本场不再恢复，也不触发原卡亡语。

点牌堆图标打开卡组。右键、Esc或手机“取消”清除待确认选择，已完成的部署与移动不撤销。手机长按卡牌约半秒查看介绍与完整技能；锁定卡不能打开。新手先进行界面导览，再练习空桌部署余灰、等待一轮、选择抽牌与献祭召唤，可在玩法手册中重看。

界面适配桌面与手机窗口，手牌和说明独立滚动。普通选牌与祭品选择保留牌桌、手牌和篝火节点；手牌固定尺寸，不随抽牌数量变形。抽牌仅从牌堆平移到手牌，不缩放、旋转或落地弹跳，异常时也会释放输入。

## 音效与设计来源

洗牌、抽牌、落牌使用[Kenney Casino Audio](https://kenney.nl/assets/casino-audio)纸牌录音；燃烧采用Ezwa／Dinamic的Flare火焰录音改编（CC-BY-SA 3.0）。刀剑来自audione，怪物与弓箭来自Superpowers，重击来自Kenney；圣光、灵体、法术和金辉宝石提示为原创合成。全部音频内嵌，音效与音乐独立，关闭音效即时停止。逐项来源、独立改编WAV及完整许可见[audio/](audio/)。

按钮与牌桌参考Wesnoth与Forge，成品使用原创CSS，详见[设计参考](DESIGN.md)。字体与音效许可随试玩包保留。
