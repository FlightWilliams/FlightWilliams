# 0.18.1 · 幽邃主教群献祭时机显示

实际复现的顺序是：第1回合Boss后手部署余灰，双方攻击结算完毕后切到第2回合；第2回合Boss先手，将上一回合存活的余灰献祭并召唤随从。旧界面把这两个回合的动作连续播放，记录也没有回合分隔，看起来像刚放下就献祭。

幽邃主教群的主动技能仅在己方至少三张牌、生命不足时回血；主题卡组没有零费怪或立即献祭的特权。双方仍须等祭品入场回合结束，下一回合才可献祭。

本次更新：

- 后手转Boss先手时，中央先显示新回合提示，再播放Boss部署，分开前后两轮动作。
- 双方场上的余灰显示“新入场”或“可献祭”，敌方新牌也使用新入场的视觉状态。
- 战斗记录加入明确回合分隔，献祭记录注明所属方、格子和卡牌入场回合。
- 玩法手册补充连续部署的原因与成熟标记。

验证：幽邃主教群专项9组逻辑检查、6组真实浏览器流程检查通过；包括全部12张主题牌的双方开局、混合新旧余灰、回合提示必须先于第二轮召唤、四种窗口尺寸。96位Boss共392次部署、167次献祭的抽样全部满足入场回合早于献祭回合。原战斗14组、续玩12组和点牌交互12组回归通过。

卡牌数值、Boss技能效果、先手轮换及献祭成熟规则沿用0.18。既有卡组和存档保持兼容。
