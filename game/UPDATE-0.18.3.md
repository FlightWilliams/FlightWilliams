# 0.18.3 · 中英文按钮与双语搜索

战斗顶部音效按钮右侧新增语言切换，中文界面显示English，英文界面显示中文；窄屏分别简写为EN和中。首页保留中文／English按钮。选择语言保存到当前浏览器，刷新后沿用；切换不会重开战斗、重抽手牌或重置选牌。

原版988张卡牌名称与介绍、主要界面、技能、规则、教程及台词均提供英文显示。内部卡名与存档键不变，已有收藏、牌组、身份和未完成对局可直接续玩。

卡牌图鉴和卡组管理的搜索框始终支持中文及英文，不受当前界面语言影响，英文忽略大小写。可以搜索中文原名、英文名、金辉名、能力词（Flying、Guard、Draw、Heal、Growth、Deathrattle等）与属性（Fire、Ice、Physical等）。未获得卡仍保持封存，搜索不会解锁或暴露隐藏卡牌。

轻量入口与延迟音频继续保留。网站部署包、内嵌单文件和离线试玩ZIP同步更新；`python3 build.py`可从本目录源码与翻译数据重新构建。
