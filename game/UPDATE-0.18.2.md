# 0.18.2 · 网页首屏与微信兼容

网站入口从约2.93MB的内嵌单文件改为约6KB的静态首屏，再加载核心逻辑与样式。篝火图片、录音音效使用独立版本资源，音效在游戏就绪后延后载入；暂不可用时保留合成声音，图片和声音不作为进入游戏的前置条件。30首音乐继续本地合成，不依赖外部音乐站。网站所需文件均同源。

下载慢时仍可看到标题；下载失败或旧浏览器未能解析游戏时，提供重试、复制链接和在系统浏览器打开的说明，不再只剩空白。没有恢复原来的阻塞进度页面。资源文件名包含内容版本，便于缓存；Cloudflare Pages部署包包含缓存规则。

兼容层去除首屏和现用技能的fromEntries/flatMap依赖；动画API缺失、异常或动画完成事件挂起时，位移、攻击、燃烧和生命浮字会降级，不阻断战斗。音频恢复被浏览器拒绝时不影响游戏。较老且无法解析可选链等语法的浏览器会显示恢复说明，仍建议更新微信和系统。

验证：11种受限浏览器变体、6组网站流程通过，覆盖静态首屏、主程序下载失败、媒体加载失败仍可开始/出牌/结束回合/续玩、录音随后就绪、存储受限和四种窗口。战斗14组与幽邃主教群9组回归通过。模拟2Mbps下载、150ms延迟、gzip与冷缓存：旧入口首屏约5.8秒，新首屏约0.2秒、新游戏就绪约1.7秒。该结果是本地Chromium网络模拟，不是大陆公网或iPhone微信实机承诺。

988张卡牌、96位Boss、卡组与存档规则保持。离线试玩ZIP仍提供完整内嵌单文件；网站发布时应使用网站部署ZIP，保留index.html和assets目录一起上传。

域名不可访问、微信拦截和运营商连通性无法靠网页代码保证解决。Cloudflare默认pages.dev域名需在目标网络实测；新域名与旧域名的本地存档独立。
