# 96位Boss的专属牌组

每位守关者有独立的随从候选名单、地区主题和配合主动技能的打法。开战时只从本Boss的候选里组成有限牌组，再正常洗牌、发牌；不会从全作品随意混入无关Boss，也不会修改卡牌原有数值。

第1／2／3关卡层级分别组成16／18／20张牌。每组至少55%为零费或一费，签名Boss固定1张，其余同名至多2张；昂贵卡最多2／3／3张。实际抽取顺序随洗牌变化。空牌桌、基础起手5张、余灰须存活一轮，以及保护优势牌的电脑决策保持原规则。

下表列出候选名单，便于检查角色风格；候选不代表每局都会全部抽到。技能的实际代价与回合限制见[BOSS-SKILLS.md](BOSS-SKILLS.md)，配置见[boss-decks.json](boss-decks.json)。
