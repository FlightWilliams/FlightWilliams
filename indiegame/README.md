# 灯誓牌 · Lantern Oath

作者：Will Wang。原创克苏鲁悬疑卡牌项目，中文与English可在首页左下角切换，战斗中也可点击音效旁的语言按钮。六处现场依次为雾镇、钟楼、灰厂、沉港、雪站、白室。玩家醒来后发现一份写着自己姓名、日期却是明天的失踪案卷，沿撤离路线查明当晚的经历与寄件人。只有六位关键人物的卡牌会新增同行者；其他对手的卡牌代表收录记录。每章最终奖励固定为本章三位主导人物，金卡已拥有或没有金卡版本时提供普通版；调查结局不要求招募指定人物。通关全部96关后，主角提着同一盏灯走入晨光，却回到雾镇最初的值班室并失去记忆；玩家对上一轮的记忆仍在，灯圈刻痕、书面记录、伙伴约定、收藏、牌组与重战解锁保留。每次完整通关都会开启更困难的下一周目。

守夜人诺亚保存值班记录，艾莉残影见证灰厂的撤离，灯塔守护者伊莱帮助核对末班船。三人的证词分别解释玩家从哪里来、在火场做了什么、怎样离开码头。卡面使用羊皮纸色和硬朗墨线，人物保留自然五官与职业服饰，动物和物件保留各自的形象。

守夜人名为诺亚（Noah），灯塔守护者名为伊莱（Eli）。96位主线Boss与12位其他可装备技能的Boss以身份加人名显示，例如“守夜人诺亚”（Night Watch Noah）；普通与金卡共用同一显示名和人物身份，以金色牌面区分稀有度。108项技能具有独立的故事名称和引言，规则效果、代价、冷却、AI与已有存档标识保持不变。姓名、职业和技能名均支持中英文搜索。完整对照表见`story/bosses.zh-CN.md`与`story/bosses.en.md`。

剧情由诺亚、芬恩、亚伯、艾莉残影、伊莱、阿尔玛六位关键人物贯穿，每章由其中三人主导。每章第1、8、16关保留重点场景，其余对局使用简短的调查进展；配角可提供旁证或阻挠，不再逐一铺开人物传记。阅读发生在发牌、首关掷币与Boss部署之前，可直接开始或跳过。返回主页、刷新后仍恢复这段出场与已准备的牌序；已在进行的旧存档继续原对局。调查手记可只读重看当前Boss出场。全部96篇由`data/boss-entrances.json`提供，随构建导出到`story/entrances.zh-CN.md`和`story/entrances.en.md`。

叙事围绕同一次撤离事件推进，每章交代当前问题、核实结果和前往下一处的理由；悬疑来自证词与记录的差异，不再给每个角色另设一件无关异象。开场、六章入场与收尾、同行者对白均有中英文版本；完整剧情稿位于`story/zh-CN.md`和`story/en.md`，包含结局，由构建从同一份剧情数据自动导出。

六章依次核对失踪案卷、求救录音、灰厂交接、沉港船册与雪站到站回执，最终在白室解释寄件人与日期。同一盏便携提灯贯穿撤离路线：在停电的灰厂照检修道，船上照担架系带，雪站照名单与回执，白室照亮寄件记录。它承载“灯在我手里，后面的人就还有路”的约定，不替代证据判断。结局确认救援经过与失踪案卷的来由，走入晨光后却回到起点。主角会忘记上一轮，玩家能凭自己的记忆识别旧路；灯的磨损、纸面证据和伙伴承诺留下，已查明的事实继续成立。敌人随周目持续增强，每次返回都比上次走得更深。

击败一位主线Boss后，选择一张奖励就直接进入下一关。出战满36张时，新奖励进入备用，关间不强制打开整理页；章节末领取奖励后进入本章收尾。

点击可打出的手牌后，卡牌悬浮并跟随鼠标；点击我方合法格子落牌。手机支持先点手牌再点格子，也支持选牌后按住我方牌桌滑动预览、松手落牌。预览时拿起的卡与对位敌卡显示绿色向上／红色向下的属性箭头，落牌后保留。献祭仍需先选足够的成熟友军；取消、Esc或右键放回尚未打出的手牌。手牌横向滑动和长按详情继续可用。

牌桌随六章逐步由暖转冷：雾镇暖棕琥珀、钟楼赭铜、灰厂灰橄榄、沉港灰青、雪站冷蓝绿，白室回到原有冷绿色。小关卡沿用所在章节的色调，重战和恢复存档也使用对应章节配色；减少动态效果设置会关闭色彩过渡。

玩家的7点生命由七个独立火苗表示：亮起表示剩余生命，熄灭的轮廓表示已损失生命；回复生命会重新点亮相应火苗。

我方Boss卡在场时可装备战技。装备成功会收起说明，按钮切换为“发动战技”；电脑悬停、手机点按可查看当前效果，再点击提示中的发动按钮确认。实际发动后，变化的攻击、生命、费用或护盾以对应数字反馈显示；攻击后结算的战技在实际结算时显示，查看和准备不会扣除代价或提前播放数值变化。

988张卡牌、96场守关战斗、108个Boss主动技能、30首原创合成配乐。每方7点生命、5条战线，保留献祭、飞行、走位、死亡触发效果、技能余芯代价和隔回合冷却、金色收藏、死亡身份、卡组管理及续玩规则。卡名、介绍、场景、技能名、台词、契币和程序头像使用本项目设定。

- `index.html`：轻量网页入口，和`assets/`一起部署。
- `standalone.html`：完整内嵌单文件，便于本地试玩。
- `lantern-oath-web.zip`：Cloudflare Pages直接上传包，压缩包根目录已放好入口。
- `data/`：卡牌、关卡、技能、牌组、图案方向、台词、音乐谱面与英文翻译。`card-names.json`提供中英文显示名，Boss身份放在人名前，`card-stories.json`提供新介绍，`loop-story.json`与`companion-dialogue.json`串联章节和伙伴故事。
- `src/`：运行模板及独立的契币、档案头像、故事与合成音效代码；`horror-theme.css`提供旧纸、墨绿牌桌与金边稀有牌外观，`chapter-theme.css`控制六章牌桌由暖转冷。
- `tests/`：机械数据基准、浏览器检查和结果。
- `story/`：可独立阅读的完整中英文剧情稿，随网站部署包提供。

## 构建与本地预览

需要Python 3，无第三方Python依赖：

```sh
python3 build.py
python3 -m http.server 8000
```

浏览器打开`http://localhost:8000/`。构建会更新入口、带内容指纹的资源、单文件版和网站部署包。`?lang=en`可以直接进入英文版。

数据检查：`python3 tests/data_check.py`。浏览器检查需Node.js、Playwright及Chromium，可用`INDIE_TEST_URL`指定本地服务地址。

周目检查：`npm run test:spiral`，验证真实通关按钮从终章进入下一周目、96关的Boss及随从持续增强、存档刷新与旧存档迁移。敌方非召唤卡（余芯除外）每增加一周目生命加1，攻击在第2、4、6周目等轮次各再加1；玩家卡牌、召唤物和首周目数值保持原样。

战术检查：`npm run test:ai`。Boss在所有关卡都会比较合法祭品和落点、优先防止致命伤害，避免为弱牌献祭优势单位；随96关进度增加候选搜索、下一回合预测与连续出牌规划。技能发动前评估收益与余芯代价，移动时同时检查被让出的战线。预测只读取公开牌桌和Boss自己的手牌，不查看玩家隐藏卡牌；卡牌数值、费用、技能效果和冷却规则保持不变。

短名与剧情检查：`npm run test:story`。内部卡牌标识保持不变，旧卡组、收藏和未完成对局直接使用新的显示名与介绍；首页、规则页可打开调查手记。卡牌库和卡组搜索始终同时支持中文、英文名称与技能关键词，不受当前界面语言影响。

悬疑主题检查：`npm run test:horror`，覆盖三位核心人物的中英文详情、988张静态SVG头像及缓存、490份双语对白、旧存档对白更新和手机金辉牌显示。

双项目语言与搜索检查：`npm run test:language`，可用`INDIE_TEST_URL`和`GAME_TEST_URL`指定两个站点，或用`LANGUAGE_TEST_TARGET=indiegame`只检查本项目。

共享音效检查：`npm run test:audio`，覆盖采样与WAV一致性、30首独立侦探谱面的路由、实际音效渲染、静音停止、加载失败回退和单文件离线播放。

独立配乐检查：`npm run test:music`，验证30首侦探器乐的实际渲染、音量、关卡路由、静音和后台恢复，并导出六章及首页试听。

人物面孔检查：`npm run test:portraits`，验证真实五官与轮廓差异、六位关键人物、金卡同脸、特殊形象、中英文与手机牌桌，并导出人物对比图。

双项目战技操作检查：`npm run test:player-skills`，覆盖装备后收起、悬停与点按查看、确认发动、实际数值动画、冷却及手机布局。

章节配色检查：`npm run test:palette`，覆盖六章配色、小关卡沿用、续玩与重战、首尾颜色基准及手机布局。

## 发布与存档

在Cloudflare控制台选择Workers & Pages → Pages → 直接上传，创建一个新项目，上传`lantern-oath-web.zip`，部署后以控制台显示的实际网址为准。默认测试域名的连通性需要用朋友所在网络及微信实际检查。

本项目使用独立的`lo_`存档键，不读取或改写其他项目的收藏、卡组和进度。存档仍按浏览器与域名保存，换域名不会自动迁移。后续更新应使用同一项目和网址。

牌桌上的“返回主页”会先保存当前主线，再离开对局；主页主按钮显示“继续游戏”，恢复原来的关卡、回合、生命、牌桌、手牌、牌库与待选效果。返回主页后刷新仍停留主页。发牌与战斗结算中暂时禁用返回，存储失败会留在牌桌；新手练习和重战不会覆盖主线。`npm run test:home`覆盖返回、继续、刷新、未领奖励及手机按钮可达性。

## 美术、音频与许可

守夜灯与契币是新绘制的SVG；牌面采用接近`game`的美式卡牌线描风格，以羊皮纸底色、硬朗轮廓、交叉排线和明确明暗表现人物职业、自然动物与日常物件，不使用影视或游戏截图。人物保持成年人的正常比例、五官和严肃自然的表情，动物保留各自的外形，不采用圆脸童绘或恐怖怪脸；人物使用固定的脸型、年龄、眉眼、鼻形、发型、胡须、眼镜与表情组合；六位关键人物各有明确面貌，同职业配角也有不同的脸，刷新或切换语言不会改变。金卡与普通版使用同一人物形象。落水树灵绘为树人，菌人绘为蘑菇人；门缝泥团绘为木门，亚伯保留一只角，湿衣羊使用羊毛与四蹄轮廓，闭眼残响为布带蒙眼的人。卡名与描述避免尸体、骸骨等意象，例如“枯叶路人”；显示名独立于存档标识，已有收藏和牌组继续有效。图像缓存且不使用逐帧滤镜。音效与`game`共享同一份录音采样及合成提示，配乐独立编配为30首克制的侦探器乐，以吉他、温暖电钢琴、木贝斯和轻刷鼓为主，保留忧郁与调查时的节奏，减少阴森持续音和刺耳音色；首页与胜负段也采用相同方向，均在本地合成。录音延迟加载，不阻塞牌桌；素材失败时使用合成回退。纸牌与多数战斗录音采用CC0，燃烧改编采用CC-BY-SA 3.0；逐项署名、WAV与许可在`audio/`，其中11个旧MP3采样尚无逐项授权记录。手写署名字体使用Dancing Script子集，按SIL OFL 1.1保留许可。详见`CREDITS.txt`及`assets/font-OFL.txt`。

新设定与新图案不能替代商用前的名称、商标和素材授权审查；本项目不作法律风险为零的保证。
